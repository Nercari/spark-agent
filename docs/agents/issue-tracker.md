# Issue Tracker Configuration

## Type
Local Markdown (`.scratch/`)

## Location
- Issues, feature specs, and task tickets are stored as markdown files under `.scratch/`.
- File naming convention: `.scratch/ISSUE-<number>-<slug>.md` or `.scratch/TICKET-<number>-<slug>.md`.

## Workflow
1. Create a markdown ticket in `.scratch/` with appropriate triage frontmatter/headers.
2. Update ticket status in-place as development progresses.
3. Link related ADRs (`docs/adr/`) and domain context (`CONTEXT.md`).
