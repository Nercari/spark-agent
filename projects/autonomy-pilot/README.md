# Autonomy Pilot 1: Integration Harness & Evidence Baseline

> **IMPORTANT CLASSIFICATION NOTICE**:
> Autonomy Pilot 1 is a deterministic **LOCAL INTEGRATION HARNESS**.
> Its Session Alpha/Beta/Gamma objects validate persistence, atomic CAS, telemetry, and lifecycle algorithms across reconstructed local Python session objects within CI and local test runs.
> They are **NOT** proof of genuinely separate, autonomous live Spark conversations.
> All autonomy metrics generated by `runner.py` are **harness metrics** and validate underlying code and data structures, not live host LLM autonomy.

---

## Purpose & Scope

1. **Continuous Integration Coverage**: Provides deterministic regression testing for declarative memory classifiers, version store branching/rollback, SQLite telemetry persistence, and progressive episodic retrieval.
2. **Algorithm Verification**: Enforces atomic CAS invariants, unique active-key constraints, and causal reflection chains under isolated test conditions without flakiness.
3. **Evidence Distinction**: Strictly separates code/harness verification from live runtime interactions.

---

## Harness Workload Structure

- **Session Alpha (Reconstructed Local Session 1)**
  - *Task 1*: Validates semantic classification and storage of project conventions (`canonical_export_format = compact_json`).
  - *Task 2*: Validates baseline skill execution against simulated metadata.
  - *Task 3*: Simulates non-transient schema failure, verifies recovery via `validate_headers=True`, and triggers automated procedural synthesis/commit of skill `v2`.
  - *Task 4*: Normal task completion and lifecycle state verification.

- **Session Beta (Reconstructed Local Session 2 - Fresh Storage Connection)**
  - *Task 5*: Verifies declarative memory retrieval and application without prompt re-seeding.
  - *Task 6*: Verifies learned skill `v2` reuse achieving direct success with 0 recoveries.
  - *Task 7*: Verifies atomic CAS supersession upon receiving a user correction (`jsonl`), marking old truth as `SUPERSEDED` and new truth as `ACTIVE`.

- **Session Gamma (Reconstructed Local Session 3 - Fresh Storage Connection)**
  - *Task 8*: Verifies corrected memory reuse (`jsonl`) without falling back to superseded values.
  - *Task 9*: Verifies lightweight episodic summary indexing and progressive evidence retrieval without user-provided TaskRun IDs.
  - *Task 10*: Consolidates harness execution metrics.

- **Controlled Local Safety Test**:
  - Deploys temporary corrupted skill child `v3` into local version store.
  - Verifies that failure triggers `CuratorTriggerPolicy` and restores parent `v2` via `CuratorExecutor`.
