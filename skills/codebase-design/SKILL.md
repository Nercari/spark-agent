# Codebase Design

Use this skill when designing modules, structuring abstractions, or defining public interfaces.

## When to Use
- Designing new modules, subsystems, or boundaries
- Refactoring shallow interfaces into deep modules
- Defining architectural seams and decoupling components

## When NOT to Use
- Routine implementation of already-specified interfaces
- Trivial script authoring
