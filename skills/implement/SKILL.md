# Implement

Build work described by a spec or tickets using strict test-driven development.

## When to Use
- Implementing scoped feature tickets or specifications.
- Writing production code backed by unit and integration tests.

## When NOT to Use
- High-level architectural planning or spec writing (use `user:to-spec`).
- Investigating unresolved bugs (use `user:diagnosing-bugs`).
