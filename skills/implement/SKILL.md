# Implement

Use this skill to implement specified tickets and features following TDD discipline.

## When to Use
- Implementing features with ready specifications or issue tickets
- Executing red-green-refactor TDD cycles

## When NOT to Use
- Requirements gathering or exploratory research without a spec
