# Domain Modeling

Actively build and sharpen a project's domain model, terminology, and ADRs.

## When to Use
- Clarifying ambiguous domain terminology or entity relationships.
- Drafting or revising Architecture Decision Records (ADRs) or CONTEXT.md.

## When NOT to Use
- Implementing code tickets directly (use `user:implement`).
- Triaging issues (use `user:triage`).
