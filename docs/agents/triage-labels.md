# Triage Labels & Workflow

The canonical triage roles and labels for issues and task tickets:

| Role / Label | Meaning | Action / Next Step |
|---|---|---|
| `needs-triage` | Newly submitted issue or ticket awaiting initial assessment. | Review problem statement, reproduction, and seams. |
| `needs-info` | Missing reproduction steps, design decisions, or clarifying context. | Request specific input from user or run discovery. |
| `ready-for-agent` | Fully specified, bounded, and testable task suitable for agent execution. | Pick up for TDD / implementation. |
| `ready-for-human` | Requires human judgment, account credentials, physical actions, or external approval. | Escalate to user. |
| `wontfix` | Out of scope, duplicate, or rejected request. | Close with concise reasoning. |
