# To Tickets

Use this skill to break down specifications into vertical-slice task tickets with explicit dependency edges.

## When to Use
- Decomposing feature specifications into actionable task tickets
- Defining vertical-slice tracer bullets and dependency graphs

## When NOT to Use
- High-level roadmap planning without a feature spec
