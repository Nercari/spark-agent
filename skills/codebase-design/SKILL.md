# Codebase Design

Shared discipline and vocabulary for designing deep modules with clean seams.

## When to Use
- Designing new module interfaces, class hierarchies, or API contracts.
- Refactoring shallow modules into deep modules.

## When NOT to Use
- Writing unit tests without interface modifications (use `user:tdd`).
- Direct bug diagnosis (use `user:diagnosing-bugs`).
