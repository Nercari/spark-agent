# Domain Modeling

Use this skill to model domain concepts, maintain ubiquitous language, and document ADRs.

## When to Use
- Clarifying ubiquitous language or domain entities
- Documenting Architecture Decision Records (ADRs)
- Maintaining CONTEXT.md glossary

## When NOT to Use
- Direct feature code authoring without domain changes
